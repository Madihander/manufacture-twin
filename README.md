# Цифровой двойник завода «СарыаркаАвтоПром»

Прототип для Qostanai Industry Hackathon 2026, кейс №2 АО «Группа компаний Аллюр».

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

## Стек

React + TypeScript + Vite, Tailwind CSS v4, shadcn/ui (Radix), zustand, Recharts, three.js (@react-three/fiber, drei).

## Структура

- `src/` — приложение
- `design/` — макеты из Claude Design (`*.dc.html`), источник для вёрстки
- `docs/` — промпты и проектные заметки
- `assets/kenney/` — 3D-модели Kenney (CC0)
