# Цифровой двойник завода «СарыаркаАвтоПром» — контекст проекта

Хакатон Qostanai Industry Hackathon 2026, кейс №2 АО «Группа компаний Аллюр». **Demo Day — 16.10.2026.**
Общение с пользователем — на русском. Интерфейс — на русском.

## Что строим
Веб-MVP цифрового двойника автозавода: 2.5D-изометрическая карта цеха + аналитика + «ИИ-диспетчер».
Требования кейса: визуализация участков и оборудования; KPI (производительность, загрузка, простои, качество);
инциденты и отклонения; панель для руководителей; прогноз простоев и узких мест (желательно ИИ).
Критерии жюри: применимость, инновационность, качество визуализации, аналитика и ИИ, презентация.

## Запуск и проверки
- `npm run dev` — http://localhost:5173 (в `.claude/launch.json`: `app` и `design` — статический сервер макетов на :5500)
- `/?showcase` — витрина служебных окон (настройки, заявка ТО, загрузка, пустые состояния)
- `npx tsc -b` — типы; `npx oxlint src` — линт; `npx vite build` — сборка
- `npm run sim:check` — калибровка симуляции и прогнозов в консоли; `npx tsx scripts/overlap-check.ts` — кузова в сцене не перекрываются

## Стек
Vite + React 19 + TypeScript, Tailwind v4, shadcn/ui (Radix, пресет nova, компоненты правлены под дизайн),
zustand, three.js через @react-three/fiber + drei, Recharts (для «Сводки»), lucide, sonner.
Шрифты локально (@fontsource Inter, JetBrains Mono) — чтобы демо работало без интернета.

## Структура
- `design/*.dc.html` — макеты из Claude Design (Design System, Топология, Сводка, Сценарии, Служебные окна). Источник вёрстки. Открывать через сервер `design`.
- `docs/claude-design-prompt.md` — промпты, по которым делался дизайн.
- `src/data/` — `seed.ts` (данные кейса один в один), `history.ts` (история октября), `plant.ts` (участки, оборудование, модели).
- `src/sim/` — `engine.ts` (дискретная симуляция смены), `model.ts` (такт, станции, сценарий остановок),
  `telemetry.ts` (24 датчика — детерминированные функции времени), `metrics.ts` (KPI, статусы),
  `predict.ts` (прогнозы ИИ кодом), `useTwin.ts` (производные данные на снимок), `clock.ts`.
- `src/store/` — `sim.ts` (время, скорость, выбор, вкладки, слои, камера), `settings.ts` (пороги, persist), `maintenance.ts` (заявки ТО), `ui.ts`.
- `src/components/twin/` — экран «Топология»: шапка, список участков, полоса потока, оверлей сцены, `panel/*` (Обзор/Участок/Оборудование/Кузов/ИИ), `ai/*` (чат + локальные ответы).
- `src/components/service/` — служебные окна. `src/scene/` — 3D: `layout.ts` (геометрия), `Factory`, `Cars`, `Labels`, `CameraRig`, `TwinScene`.
- `assets/kenney/` — модели Kenney (CC0): car-kit, city-kit-industrial_2.0, factory-kit_3.0 (папки `GLB format` + `Textures`). Ещё не подключены.

## Ключевые решения
- **Время смены:** секунды от 16:00 (смена 2, 15.10.2026). Демо стартует с 21:42:10 (`DEMO_START_T`), скорость 8×.
  Вся смена считается один раз при старте (~170 мс), снимки каждые 10 с → перемотка мгновенная; «Сценарии» = новый прогон с другими параметрами (`RunParams`).
- **Данные кейса:** строки «план 120 / факт» трактуем как **одну смену** (иначе мощность 2 640/мес при цели 5 500). 01–02.10 смена 1 — реальные; остальное моделируется детерминированно (seed).
- **План по моделям (из кейса): Onix 2 500, Cobalt 1 800, JAC J7 500 = 4 800 < 5 500.** В старых промптах/макетах было наоборот — верно как здесь.
- Мощность линии: 22 рабочих дня × 2 смены × 120 = 5 280 < 5 500 — вывод для презентации.
- **Прогнозы считает код** (тренд параметра к границе нормы → логистическая вероятность; брак; узкое место; месячный план). LLM только пересказывает. Чат сейчас отвечает шаблонами `ai/localAnswer.ts` — это же офлайн-запас для защиты.
- Цифры честные из симуляции, могут отличаться от макетов (к 21:42 выпуск 68 при плане 86, OEE линии ~80 %).
- Статусы участков пересчитываются по порогам из «Настроек» (OEE ≥ 85, брак ≤ 2 %, простой ≤ 60 мин/сут).

## Подводные камни
- drei `<Html>`: не монтировать/размонтировать на лету (React 19 ругается «synchronously unmount a root») — держать смонтированным и скрывать содержимое.
- Окно браузера в превью часто скрыто → rAF троттлится, анимации/время стоят; проверять через JS, скриншоты уменьшены.
- Python на Windows пишет CRLF — git нормализует в LF (`.gitattributes`), это ок.
