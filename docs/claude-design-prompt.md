# Промпты для Claude Design — «Цифровой двойник СарыаркаАвтоПром»

## Как пользоваться

1. В первое сообщение приложите: скриншот HARBOR (референс стиля) и логотип Allur (SVG или PNG на прозрачном фоне).
2. Отправляйте блоки по одному: **Блок 0 → Блок 1 → … → Блок 6**. После каждого блока проверьте результат и поправьте, прежде чем идти дальше. Так дизайн получается заметно точнее, чем одним огромным промптом.
3. Цифры в промптах согласованы между собой и с тестовыми данными кейса. Не меняйте их по отдельности, иначе экраны начнут противоречить друг другу.
4. Результат для меня: скриншоты всех экранов и состояний, а если Claude Design умеет экспортировать код — ещё и код.
